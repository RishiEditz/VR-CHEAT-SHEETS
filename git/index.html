Quick quiz

Ten questions on the commands above. Pick an answer to see if you were right.

1. Which command turns the current folder into a Git project?

git init creates the hidden .git folder that tracks the project.

2. Which command stages all changes in the current folder?

git add . stages everything in this folder for the next commit.

3. Which command creates a new branch and switches to it?

The -c flag of git switch creates the branch and moves you onto it.

4. Which command sets unfinished changes aside so you can switch branches?

git stash saves your changes. git stash pop brings them back.

5. Which command downloads remote changes without merging them?

git fetch updates your copy of the remote. Your files stay as they are.

6. Which command undoes an old commit by adding a NEW commit?

git revert is safe for shared history because it never rewrites past commits.

7. Which command lists recent positions of HEAD, so you can recover lost commits?

The reflog remembers where HEAD has been, even after a reset.

8. Which command shows who last changed each line of a file?

git blame shows the author and commit for every line.

9. What is a .gitignore file for?

Files listed in .gitignore, like node_modules/, stay out of your commits.

10. Which command makes git st run git status?

Aliases are set with git config, here under the alias.st key.
